# Gaming Hub 🎮

A comprehensive HTML5 gaming website featuring 22 classic and modern games with integrated leaderboard system.

## Features

✨ **22 Games Available:**
- Classic Games: Snake, Flappy Bird, Memory, Tic Tac Toe, Pong, Simon Says
- Puzzle Games: Tangram, 2048, Hangman, Wordle-style, DNA Game, Gravity Puzzle
- Action Games: Space Invaders, Asteroid Dodger, Target Practice, Breakdance Party
- Strategy Games: Dice Wars, Sort The Court, Choose Your Adventure
- Creative Games: Incredibox, Infinite Painter
- Atmospheric Games: Dark Room

🏆 **Leaderboard System:**
- Track top scores for each game
- Player stats and rankings
- Local storage for persistent data
- Real-time score updates

🎨 **Modern UI:**
- Responsive grid layout
- Search and filter functionality
- Smooth animations and transitions
- Mobile-friendly design
- Dark theme with gradient backgrounds

## Getting Started

1. Clone the repository
2. Open `index.html` in a modern web browser
3. Start playing!

## Game Categories

### Classic Games
- **Snake**: Navigate and grow your snake
- **Flappy Bird**: Navigate through pipes
- **Memory**: Match pairs of cards
- **Tic Tac Toe**: Strategic 3x3 grid game
- **Pong**: Two-player paddle game
- **Simon Says**: Remember color sequences

### Puzzle Games
- **Tangram Puzzle**: Arrange geometric shapes
- **2048**: Combine tiles to reach 2048
- **Hangman**: Guess the word
- **Wordle-style**: Word guessing game
- **DNA Game**: Genetic matching
- **Gravity Puzzle**: Physics-based challenges

### Action Games
- **Space Invaders**: Shoot down aliens
- **Asteroid Dodger**: Dodge incoming asteroids
- **Target Practice**: Precision shooting
- **Breakdance Party**: Dance to the beat

### Strategy Games
- **Dice Wars**: Territory conquest
- **Sort The Court**: Kingdom management
- **Choose Your Adventure**: Story-driven choices

### Creative Games
- **Incredibox**: Music creation
- **Infinite Painter**: Digital art

## Leaderboard

Each game maintains a top-10 leaderboard. Scores are stored locally in your browser and persist between sessions.

## Browser Compatibility

- Chrome (recommended)

- Safari
- Edge
- Any modern HTML5-supporting browser

## Technical Stack

- **HTML5**: Game structure and canvas-based games
- **CSS3**: Modern styling with gradients and animations
- **Vanilla JavaScript**: Game logic and interactivity
- **LocalStorage**: Persistent leaderboard data
